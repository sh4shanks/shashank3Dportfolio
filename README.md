# Shashank Singh — Interactive 3D Portfolio

An immersive 3D portfolio built with React, React Three Fiber, Three.js and GSAP.

## About

This version is customised for **Shashank Singh** (`sh4shanks`). It keeps the original interactive corridor / rooms concept while replacing the template creator's identity, projects, metadata and contact details.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The contact form uses FormSubmit to deliver visitor messages to the portfolio Gmail address. The first submission may require FormSubmit email activation/confirmation.
